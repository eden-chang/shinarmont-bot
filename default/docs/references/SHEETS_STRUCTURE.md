# Google Sheets 구조 레퍼런스

봇이 읽고 쓰는 모든 워크시트의 컬럼 구조와 데이터 형식을 정의합니다.
새 기능 추가 시 이 문서를 기준으로 데이터 접근 로직을 작성하세요.

---

## 봇 타입별 필요 워크시트

| 워크시트 | default | store | stats | investigate |
|---------|:-------:|:-----:|:-----:|:-----------:|
| 명단    | ✅ | ✅ | ✅ | — |
| 도움말  | ✅ | ✅ | ✅ | — |
| 운세    | ✅ | ✅ | ✅ | — |
| 커스텀  | ✅ | ✅ | ✅ | — |
| 관리    | — | ✅ | ✅ | — (기본 시트에서 읽기/쓰기만) |
| 상점    | — | ✅ | ✅ | — |
| 진입    | — | — | — | ✅ (보조 시트) |
| 장소명(예: 병원) | — | — | — | ✅ (보조 시트, 장소별 1개) |

> `stats` 타입은 `store` 타입의 상위 집합입니다. store 기능 전체 + 스탯(체력·정신력 등) 기능을 포함합니다.
> `investigate` 타입은 보조 스프레드시트(`INVESTIGATION_SHEET_ID`)의 `진입` + 장소별 워크시트만 읽습니다. 소지품·스탯 업데이트는 **기본 시트**(`SHEET_ID`)의 `관리` 워크시트에 반영됩니다.

## 워크시트별 컬럼 정의

### 명단 (ROSTER)

모든 봇 타입에서 사용. 시트 접근: `self.sheets_manager.get_roster_data(use_cache=True)`

| 컬럼 | 형식 | 비고 |
|------|------|------|
| `이름` | 문자열 | 숫자만으로 구성된 이름 불가 |
| `아이디` | 문자열 | 마스토돈 아이디, `@` 제외. 숫자만으로 구성 불가 |

```python
# 접근 예시
for row in roster_data:
    name = row.get('이름', '')
    user_id = row.get('아이디', '')
```

> **시트 행 구조**: 1행=헤더, **2행=설명(무시됨)**, 3행부터=실제 데이터
> `get_worksheet_data()`는 이 구조를 자동으로 처리하여 3행부터 딕셔너리 리스트로 반환합니다.

---

### 도움말 (HELP)

모든 봇 타입에서 사용. `[도움말]` 명령어가 출력하는 목록.

| 컬럼 | 형식 | 비고 |
|------|------|------|
| `명령어` | 문자열 | 대괄호 포함 형식: `[도움말]`, `[구매/ 아이템명 / 개수 ]` |
| `설명` | 문자열 | 명령어 설명 |

---

### 운세 (FORTUNE)

모든 봇 타입에서 사용. `[운세]` 명령어가 날짜 기반으로 한 줄을 선택.

| 컬럼 | 형식 | 비고 |
|------|------|------|
| `문구` | 문자열 | 운세 텍스트. 행이 많을수록 다양한 결과 |

---

### 커스텀 (CUSTOM)

모든 봇 타입에서 사용. 동일 `명령어`가 여러 행이면 랜덤으로 하나 선택.

| 컬럼 | 형식 | 비고 |
|------|------|------|
| `명령어` | 문자열 | 명령어 이름 (대괄호 없이) |
| `문구` | 문자열 | 출력 문구. 템플릿 변수 사용 가능 (아래 참조) |
| `이미지` | URL 또는 공란 | 이미지 첨부 (PREMIUM_IMAGE_ENABLED=True 시 활성화) |

#### 커스텀 문구 템플릿 변수

| 변수 | 출력 | 예시 |
|------|------|------|
| `{시전자}` | 명령어 사용자 이름 | `한참` |
| `{은는}` | 은/는 자동 선택 | `은` |
| `{이가}` | 이/가 자동 선택 | `이` |
| `{을를}` | 을/를 자동 선택 | `을` |
| `{랜덤: A, B, C}` | A·B·C 중 랜덤 선택 | `젓가락` |
| `{NdM}` | M면 주사위 N개 합계 | `{1d100}` → `72` |
| `{NdM+K}` | 주사위 합계 + K | `{3d6+2}` → `14` |

```
# 커스텀 시트 예시
명령어    문구
패션      오늘의 패션 점수는 {1d100}점입니다.
허기      {시전자}{은는} 배가 고픕니다.
허기      배고픈 나머지 {시전자}{이가} 친구를 잡아먹었습니다.
YN        예
YN        아니오
```

동일 명령어 여러 행 → 랜덤 선택. 이 패턴으로 `YN`, `가위바위보`, `홀짝` 등을 구현.

### 관리 (MANAGEMENT)

`store` / `stats` 타입에서 사용. **캐싱 금지** — 항상 `use_cache=False`로 조회.
시트 접근: `self.sheets_manager.get_worksheet_data('관리', use_cache=False)`

명단의 `이름`, `아이디`에서 자동으로 행이 생성됨.

#### store 타입 기본 컬럼

| 컬럼 | 형식 | 비고 |
|------|------|------|
| `이름` | 문자열 | 명단에서 자동 |
| `아이디` | 문자열 | 명단에서 자동 |
| `소지금` | 정수 | 기본값 보통 0 |
| `소지품` | 인벤토리 문자열 | 형식: `아이템명: 개수, 아이템명: 개수` (아래 참조) |

#### stats 타입 추가 컬럼

위 컬럼에 더해 스탯 컬럼 추가. 어떤 컬럼을 추가할지는 운영자가 결정하며,
`PEEK_HEADER` 환경변수에 쉼표로 나열하면 `[상태 확인]` 명령어가 해당 컬럼을 표시.

```
# .env 예시
PEEK_HEADER=소지금,소지품,체력,정신력
```

| 컬럼 예시 | 형식 | 비고 |
|----------|------|------|
| `체력` | 정수 | [사용] 시 스탯으로 증감 |
| `정신력` | 정수 | [사용] 시 스탯으로 증감 |
| 기타 스탯 | 정수 또는 문자열 | 운영자 자유 정의 |

#### 인벤토리 문자열 형식

```
# 시트에 저장되는 형식
바나나: 2, 반지: 1, 사과: 3

# 코드에서 파싱
from utils.store_helpers import parse_inventory_string
inventory = parse_inventory_string(row.get('소지품', ''))
# 결과: {'바나나': 2, '반지': 1, '사과': 3}

# 코드에서 직렬화 (업데이트 시) - serialize_inventory 사용 권장
from utils.store_helpers import serialize_inventory
inventory_str = serialize_inventory(inventory)
# 아이템명 알파벳/가나다 순 정렬, 빈 항목·0개 자동 제거
```

### 상점 (SHOP)

`store` / `stats` 타입에서 사용. 시트 접근: `self.sheets_manager.get_item_data()`

**동일 `아이템명`이 여러 행이면** `[사용]` 시 랜덤으로 하나 선택 → 아이템 효과를 랜덤하게 만들 때 활용.

| 컬럼 | 형식 | 비고 |
|------|------|------|
| `아이템명` | 문자열 | `/`, `,`, `:` 사용 불가 |
| `가격` | 정수 또는 `비매품` | `비매품`이면 구매 불가, 지급/획득만 가능 |
| `설명` | 문자열 | `[설명/아이템명]`, `[상점]` 시 출력 |
| `사용문구` | 문자열 또는 공란 | `[사용/아이템명]` 시 출력. 사용 불가 아이템은 공란 |
| `스탯` | 열거값 | `체력`, `정신력`, `소지금`, `사용 불가` |
| `수치` | 정수/주사위식 또는 공란 | 사용 불가 아이템은 공란 |

#### 스탯 수치 형식

| 형식 | 의미 | 예시 |
|------|------|------|
| `10` | 고정값 +10 | 체력 +10 |
| `-5` | 고정값 -5 | 체력 -5 |
| `1d6` | 1~6 랜덤 | 체력 +1~6 |
| `3d10+5` | 3d10 결과 + 5 | 체력 +8~35 |
| `2d6-1` | 2d6 결과 - 1 | 체력 +1~11 |
| `-(1d6+3)` | 음수 주사위식 | 체력 -4~9 |

```
# 상점 시트 예시
아이템명    가격    설명                        사용문구                    스탯      수치
반지        3       노란색 보석이 박힌 은색 반지  반지가 번쩍이며 정신이 말끔해진다.  정신력    10
사과        1       아삭아삭!                    달콤한 사과의 맛!           체력      1d10
아몬드      비매품  동그란 아몬드입니다.          어라? 사실 청산가리였습니다.        체력      -(1d6+3)
아몬드      비매품  동그란 아몬드입니다.          까득! 맛이 있군요.           체력      1d3
파란 꽃병   10      관상용 아이템입니다.                                      사용 불가
```

### 진입 (ENTRY) — investigate 전용 (보조 시트)

조사 시트(`INVESTIGATION_SHEET_ID`)에 위치. `[진입/장소명]`이 이 워크시트를 조회합니다.
워크시트 이름은 `INVESTIGATION_ENTRY_SHEET` 환경변수로 변경 가능 (기본값 `진입`).

| 컬럼 | 형식 | 비고 |
|------|------|------|
| `장소명` | 문자열 | `[진입/<여기>]`로 매칭 |
| `진입 시 문구` | 문자열 | 진입 직후 출력되는 문구 |
| `현재 진입 가능` | `가능` 또는 `불가능` (선택) | `[장소 목록]`이 `가능`인 장소만 출력. 컬럼 없으면 전체 표시 |

```
# 진입 워크시트 예시
장소명    진입 시 문구                                                      현재 진입 가능
병원      소독약 향이 감도는 병원이다. [간호사], [의사], [환자]를 조사할 수 있다.  가능
학교      낡은 학교 건물이다. [교실], [복도], [교무실]을 조사할 수 있다.            불가능
```

`[장소 목록]` 명령어는 이 워크시트에서 `현재 진입 가능` = `가능`인 행의 `장소명`만 나열합니다.

**동일 `장소명`이 여러 행이면** `[진입/장소명]` 시 그중 하나를 랜덤으로 선택하여 해당 행의 `진입 시 문구`를 출력합니다. 분위기가 다른 진입 연출을 번갈아 보여줄 때 활용.

`진입 시 문구`와 `조사 시 문구`에는 **커스텀 명령어와 동일한 템플릿 변수**를 사용할 수 있습니다 (`{시전자}`, `{은는}`, `{이가}`, `{을를}`, `{과와}`, `{NdM}`, `{NdM+K}`, `{랜덤: A, B, C}`). 이 치환은 `PREMIUM_CUSTOMC_ENABLED=True`일 때만 동작하며, 비활성화 상태에서는 변수가 원문 그대로 출력됩니다.

```
# 템플릿이 포함된 조사 시 문구 예시
{시전자}{은는} 책상 서랍을 보기 위해 고개를 숙였다. 그 안에는 {랜덤: 찢어진 쪽지, 깨진 거울}{이가} 있었다.
오늘의 패션 점수는 {1d100}점입니다.
능력치는 민첩: {3d6} / 힘: {3d10+5} / 운: {1d100} 입니다.
```

### 장소별 워크시트 (LOCATION) — investigate 전용 (보조 시트)

`진입` 워크시트의 `장소명`과 **동일한 이름**의 워크시트를 각 장소마다 하나씩 만듭니다.
`[조사/조사포인트]`가 사용자의 현재 장소명 워크시트를 조회합니다.

| 컬럼 | 형식 | 비고 |
|------|------|------|
| `조사 포인트` | 문자열 | `[조사/<여기>]`로 매칭 |
| `조사 시 문구` | 문자열 | 조사 직후 출력되는 문구 |
| `획득 아이템` | 문자열 또는 공란 | 공란이면 아이템 획득 없음 |
| `개수` | 정수 또는 주사위식 | `1`, `1d6`, `2d6+3`, `-(1d6+3)` 모두 지원 |
| `변동 스탯` | 문자열 또는 공란 | 기본 시트 `관리`에 해당 컬럼이 없으면 생략 |
| `수치` | 정수 또는 주사위식 | 스탯 변화량 |

```
# '병원' 워크시트 예시
조사 포인트    조사 시 문구                              획득 아이템    개수    변동 스탯    수치
간호사         흰 가운의 간호사가 차트를 들고 있다.      메스           1       정신력       -(1d6+1)
환자           창백한 얼굴의 환자가 침대에 누워있다.                             체력         -1d4
```

> 진입 상태는 **봇 메모리**(`utils/investigation_state.py`)에 사용자별로 저장되며, 봇 재시작 시 초기화됩니다.
> `[조사]`를 진입 없이 사용하면 `"현재 아무 장소에도 진입해 있지 않습니다. [진입/장소명] 명령어를 먼저 사용해 주세요."` 안내 문구를 반환합니다.
> 기본 시트 `관리`에 `소지품` 컬럼이 없거나 `변동 스탯`에 해당하는 컬럼이 없으면, 그 항목에 대한 변동·출력은 생략됩니다.

## 코드에서 시트 접근 패턴 요약

```python
# 명단 (캐싱 가능)
roster_data = self.sheets_manager.get_roster_data(use_cache=True)

# 상점 (캐싱 가능)
item_data = self.sheets_manager.get_item_data()

# 관리 (캐싱 금지 - 항상 최신값 필요)
management_data = self.sheets_manager.get_worksheet_data('관리', use_cache=False)

# 커스텀 (캐싱 가능)
custom_data = self.sheets_manager.get_worksheet_data('커스텀', use_cache=True)

# 관리 워크시트에서 특정 사용자 행 찾기
def _find_user_row(user_id: str, data: list) -> dict | None:
    for row in data:
        if str(row.get('아이디', '')).strip() == user_id:
            return row
    return None

# ⚠️ 행 번호 계산 — _row_number 사용 (권장)
# get_worksheet_data()는 각 레코드에 _row_number 키를 자동으로 포함합니다.
# 빈 행이 중간에 있어도 실제 시트 행 번호를 정확하게 반영합니다.
for row in management_data:
    if str(row.get('아이디', '')).strip() == user_id:
        row_index = row['_row_number']  # ← 정확한 실제 시트 행 번호
        break

# 컬럼 번호 계산 (헤더에서 직접 조회, 1-indexed)
worksheet = self.sheets_manager.get_worksheet('관리')
header_row = worksheet.row_values(1)
col_index = header_row.index('체력') + 1  # 0-indexed → 1-indexed

# 단일 셀 업데이트
self.sheets_manager.update_cell('관리', row_index, col_index, new_value)

# 여러 셀 원자적 업데이트 (예: 소지품 + 스탯 동시)
self.sheets_manager.batch_update_cells('관리', [
    (row_index, inventory_col, new_inventory_str),
    (row_index, stat_col, new_stat_value),
])
```

## 캐싱 규칙

| 워크시트 | 캐싱 여부 | 이유 |
|---------|----------|------|
| 명단    | ✅ 가능 | 사용자 목록은 자주 변경 안 됨 |
| 도움말  | ✅ 가능 | 정적 데이터 |
| 상점    | ✅ 가능 | 아이템 목록은 자주 변경 안 됨 |
