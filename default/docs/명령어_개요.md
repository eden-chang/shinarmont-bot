## 일일 제한 저장 위치 요약

| 항목 | 저장 | 리셋 |
|------|------|------|
| `오늘추적`(1) · `오늘조사`(2) | **`관리` 시트 컬럼** | 스케줄러 00:00 → 0 |
| `출석`(빈칸/O) | **`관리` 시트 컬럼** (판정 기준) | 스케줄러 00:00 → 빈칸 |
| `오늘대화여부`(1) · `오늘고발`(1) · `오늘의무실`(1) | **봇 JSON** | 스케줄러 00:00 → 0 |
| `어제대화상대` `오늘대화상대` | **봇 JSON** | 00:00 이월 후 오늘 비움 |
| 투표(대상당 1행) | `투표` 시트 조회 | 일차 기준 · 재투표는 표만 덮어쓴다 |

> 추적·조사를 시트에 두는 이유: GM이 각 인물의 마을 활동량을 시트에서 바로 트래킹하기 위함.
> `출석`은 트래킹 겸 **판정 기준**이라 시트에 둔다(GM이 칸을 지우면 그날 재출석 가능). 나머지 카운터는 봇 내부 JSON.

## 공개 범위(visibility) 정책

명령어마다 허용되는 툿 공개 범위가 다르다. **표: `utils/command_visibility.py`**
범위가 틀리면 **다른 모든 로직 이전에 즉시 차단**하고(시트를 읽지 않는다) 안내만 DM으로 답한다.

| 허용 범위 | 명령어 |
|-----------|--------|
| **DM 전용** | `[장소 목록]` `[진입]` `[조사]` `[추적]` `[투표]` `[대화]` `[고발]` `[결과 보고]` `[교류]` `[의무실 방문]` `[대화 끝내기]` · 관리자: `[캐시 리셋]` `[소지금 관리]` `[스탯 변경]` `[조사 개방]` |
| **팔로워 전용** | `[출석]` `[블랙잭]` `[슬롯머신]` `[크랩스]` |
| **팔로워 전용 · DM** | `[상태 확인]` `[상점]` `[구매]` `[설명]` `[사용]` `[도움말]` |
| **미등재 · 팔로워 전용 · DM** | `[양도]` |

- **`공개(public)`는 어떤 명령어도 허용하지 않는다.**
- **등록된 명령어 27개 전부 규칙이 있다.** 규칙 없이 새 명령어가 추가되면
  전역 설정(BOT1=미등재 허용)으로 조용히 새어 나가므로, 테스트가 이를 막는다
  (`test_every_registered_command_has_a_rule`).
- 표가 **유일한 기준**이다. 슬롯 전역 설정(`BOTn_ALLOWED_VISIBILITY`)보다 우선한다.
  (예: BOT1이 전역으로 미등재까지 허용해도 `[출석]`은 팔로워 전용만 받는다)
  전역 설정은 이제 **커스텀 명령어·미등록 키워드**에만 적용된다.
- 별칭도 같은 규칙을 따른다(`[탐색]`=`[조사]` → DM 전용, `[슬롯]`=`[슬롯머신]` → 팔로워 전용).
- `[가방]`은 **사용하지 않는다** — `[상태 확인]`이 소지품까지 보여 주므로 중복이라
  `BOT1_COMMAND_FILTER`에서 제외했다(규칙 자체는 되살릴 때를 대비해 남겨 둠).

### 위반 시 안내 문구 (3종)

> 이 명령어는 **다이렉트 메시지** 범위로만 사용할 수 있습니다. 위 툿을 삭제한 후, 범위를 올바르게 설정하여 다시 업로드하세요.

> 이 명령어는 **팔로워 전용** 혹은 **다이렉트 메시지** 범위로만 사용할 수 있습니다. 위 툿을 삭제한 후, 범위를 올바르게 설정하여 다시 업로드하세요.

> 이 명령어는 **팔로워 전용** 범위로만 사용할 수 있습니다. 위 툿을 삭제한 후, 범위를 올바르게 설정하여 다시 업로드하세요.

문구 템플릿은 `VISIBILITY_ERROR_TEMPLATE`(env)로 수정 가능하며, 범위 라벨은 허용 목록에서
자동 생성된다(예: 양도 → "**미등재**, **팔로워 전용** 혹은 **다이렉트 메시지**").
안내는 **항상 DM으로** 보낸다 — 잘못된 범위의 타래에 더 노출시키지 않기 위함.
