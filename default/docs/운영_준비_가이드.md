# 운영진(GM) 준비 가이드 — 매일/주기별 할 일

> 시너몬트 진행을 위해 운영진이 시트에 채우고 판단해야 하는 것들의 체크리스트.
> 봇이 자동으로 처리하는 것과 사람이 준비해야 하는 것을 구분한다. 작성 2026-07-14.

---

## 0. 원칙 — 봇이 하는 일 vs GM이 하는 일

GM은 **"콘텐츠와 판단"만** 준비한다. 배포·계산·중복 관리·집계는 봇이 한다.

| 봇이 자동 처리 (준비 불필요) | GM이 준비 (콘텐츠·판단) |
|------------------------------|--------------------------|
| 일일 카운터 리셋, 봇 JSON 정리 | 조사 내용, 진입 조건, 오늘의 환경, 능력치 수동 조정 |
| **조사 개방**(오픈 일자 21:00 자동, 버전 전환 포함) | 조사 포인트·직군·오픈 일자 **작성** |
| 소문 **발송**(무작위 수신자·DM) | 소문 **후보 선별·문구 확정**(큐레이션) |
| 부탁/지령 **DM 배포 + 보상 지급** | 부탁/지령 **내용·일정·경중** 작성 |
| 고발 +50 지급, 투표 집계·과반 판정 | 고발 진위 판단, 단상 명단 확정 |
| 능력치 회복 계산, 추적 단서 **랜덤·중복없이 배분** | 추적 단서 **풀 작성**, 상점 아이템 작성 |

## 1. 매일 아침 루틴 (5~10분 목표)

가장 중요한 매일 준비. 순서대로:

1. **오늘의 환경 / 일차 확인** — `설정` 시트. 일차는 날짜 자동(2026-07-17=1일차)이지만, 특수 환경(예: "안개", "정전")을 오늘 값으로 설정 → 조사·진입 조건에 반영.
2. **조사 개방 상태 확인** — `진입` 시트·장소 시트의 `현재 조사 가능`.
   **오픈 일자(1주-4일차 등)의 개방은 봇이 21:00에 자동으로 한다.** 평소엔 손댈 필요 없다.
   손으로 열고 닫을 수는 있고, 봇은 그걸 되돌리지 않는다(§8 참조).
3. **조사 내용 갱신** — 각 장소 워크시트. 그날 스토리에 맞춰 문구·획득물 조정.
   직군 제한은 **포인트 단위**(`조사 가능 직군`)다. 장소 단위 제한은 없다 —
   "이 장소는 군인만"은 그 시트의 모든 포인트를 군인 전용으로 두면 자연히 그렇게 된다.
4. **소문 큐레이션** — `소문` 시트. 봇이 어젯밤 행동에서 올려둔 **후보**를 보고, 내보낼 것을 골라 문구를 다듬고 `상태=확정`으로. (봇이 소문일에 무작위 수신자에게 발송)
5. **저건강·저이성 점검** — `관리` 시트. 건강 임계 이하(=강제 입원)·이성 임계 이하(=환각) 인원을 확인해 스토리 대응. (입원은 별도 컬럼 없이 건강에서 파생)
6. **고발·보고 검토** — `고발`/`부탁지령` 시트. 어제 들어온 고발 사유의 진위 판단(허위 과다 시 불이익), 결과 보고 내용을 스토리에 반영.

## 2. 특정 일차·이벤트에만

- **투표일** — 단상 명단 세팅(`설정` 또는 `고발.처리=단상`) → 플레이어가 `[투표/유죄|무죄]` → 봇이 집계·과반 판정하여 **결과 기록**(`행동로그`/공지) → **GM이 탈락 반영·밤 연출**(봇은 처분 플래그 저장 안 함).
- **부탁/지령 배포일** — 미리 `부탁지령` 시트에 적어두면(대상·일차·내용·경중·보상), 봇이 그날 자동 DM + 보고 시 보상 자동 지급.
- **스토리 비트** — 진입·조사 문구를 그날 전개에 맞춰 갱신.

## 3. 사전 준비 (개막 전 1회 + 수시 보충)

- 🔴 **`관리` 시트에 `출석` 컬럼 추가** — 출석 1일1회 판정의 **기준**이다.
  **이 컬럼이 없으면 봇이 출석을 전부 거절한다**(없는 채로 진행하면 제한이 사라져
  소지금을 무한히 받을 수 있어 의도적으로 막는다). 값은 봇이 채우니 헤더만 만들면 된다.
- 🔴 **캐릭터명 유일성 확인** — `관리` 시트에 동명이인이 없어야 한다(§4).
- **조사 시트 작성** — `진입`(장소명·오픈 일자·진입 문구), 장소 시트 9종
  (포인트·직군·오픈 일자·문구·아이템·스탯·재화), 필요 시 `예외`.
  변주(같은 이름·같은 오픈 일자 여러 행)를 쓸 때는 **아이템·스탯·재화를 통일**할 것 —
  다르면 러너가 유리한 결과가 나올 때까지 반복 조사하는 복권이 된다.
- **추적 단서 풀** — `추적` 시트(`추적1~추적5`). **인물별 최대 5개 단서**. 봇이 `[추적/대상]` 시 랜덤으로 하나 배분하되 **같은 추적자에게는 중복 없이**(§5).
- **상점** — `상점` 시트. 회복품(보급품/진통제/안정제 = 건강·이성 회복), 비매품, 설명·수치.
- **직군·비밀설정·목표** — 직군은 `관리`, 추적으로 새어나갈 **비밀설정은 `추적` 시트 단서에 직접** 써 넣음, 개인 목표는 `명단`/별도.
- **이성 임계 문구** — `이성` 시트. 인물별 `이성문구1`(이성 ≤60 시)·`이성문구2`(≤30 시)를 작성. 봇이 임계 도달 시 자동 DM(각 1회). 발송여부는 봇이 관리.
- **운세·커스텀 문구** — `운세`(출석 시 노출)·`커스텀`(YN 등).

## 4. 상시 모니터링

- **엔딩 분기 추적** — 고발·투표·지령 수행이 엔딩에 미치는 영향을 `행동로그`/`투표`/`고발`로 집계.
- **신규 참가자** — `명단` 추가 → `관리` 자동 생성 → 직군 부여(비밀설정은 `추적` 시트에).
  ⚠️ **캐릭터명은 반드시 유일해야 한다** — 조사 로그·예외 시트가 캐릭터명을 키로 쓰므로
  동명이인이 생기면 두 사람의 **일일 조사 횟수·현재 위치·예외 권한이 섞인다.**
  (봇이 동명이인을 감지하면 관리자에게 DM으로 알린다.)
- **봇/시트 점검** — 컬럼 깨짐·봇 가동 확인.
- **관리자 DM 확인** — 봇이 아래 상황에서 관리자 계정으로 DM을 보낸다. **오면 반드시 조치할 것**:

| DM 내용 | 뜻 | 조치 |
|---------|-----|------|
| `{일차} 조사 n건 개방 완료` | 정상 자동 개방 | 없음(확인만) |
| `⚠️ … 개방이 부분 실패` | 일부 시트를 못 열었다. **실행 기록을 남기지 않았다** | 원인 수정 후 `[조사 개방/일차]` 재실행(멱등) |
| `⚠️ 실행되지 않은 조사 개방이 있습니다` | 개방 시각에 봇이 꺼져 있었다 | 확인 후 `[조사 개방/일차]`로 수동 개방 |
| `⚠️ 로그 기록 실패` | 조사 로그를 못 썼다. **보상도 주지 않고 중단했다** | 로그 시트 상태 확인(권한/이름/쿼터) |
| `⚠️ 보상 반영 실패 … 수동 정산` | 로그엔 남아 횟수는 소모, 보상은 미지급 | `관리` 시트에서 수동 보정 |
| `⚠️ '관리'에 '출석' 컬럼이 없습니다` | **전원 출석 불가 상태** | 컬럼 추가 |
| `⚠️ 버전 중복 경고` | 같은 이름이 다른 오픈 일자로 동시에 '가능' | 구버전 행을 닫기 |
| `⚠️ 동명이인` | 캐릭터명 중복 | 이름을 유일하게 수정 |

## 4-1. ⚠️ 다른 봇에 의존하는 것 (이 봇이 처리하지 않음)

- **`관리` 시트 `출석` 컬럼의 00:00 초기화(O → 빈칸)** 는 **별도 스케줄러 봇**이 한다.
  - 이 봇은 `출석` 칸을 비우지 않는다.
  - **그 봇이 멈추면 칸이 `O`인 채로 남아 그날 아무도 출석하지 못한다.**
    자동 복구 수단이 없으므로, 출석 문의가 들어오면 **가장 먼저 이 칸을 확인**하고
    필요하면 손으로 비울 것.
  - 반대로 `오늘추적`·`오늘조사` 카운터는 **이 봇**이 00:00에 처리한다. (능력치 일일 자동 감소는 폐지됨 — 2026-07-18, 수치는 GM이 수동 조정)

## 5. 추적 단서 메커니즘 (확정) — 형식 상세: `추적_시트_형식.md`

**목표**: 인물당 최대 5 단서, 추적하면 랜덤 수령, **추적자별 중복 없음**.

- **`추적` 시트(GM이 채움)**: `이름`(대상) + `추적1~추적5`(단서 텍스트, 빈 칸 허용). 인물별 단서 수는 0~5개 자유.
- **`추적기록` 시트(봇 자동)**: `이름`(추적자) + `추적기록`(받은 `대상번호` 콤마 목록, 예 `데이비드2, 메리5`).
- 봇 동작: `[추적/대상]` → 대상의 비어 있지 않은 단서 중 **이 추적자가 아직 안 받은 것** 하나를 랜덤 → DM → `추적기록`에 토큰 append. 전부 받았으면 "더 알아낼 것이 없다.".
- **GM은 `추적` 시트에 단서만 채우면 됨.** 중복 없는 배분·이력은 봇이 관리(재시작에도 시트로 유지).

## 6. 소문 큐레이션 플로우 (확정)

**목표**: "봇을 거친 눈에 띄는 행동"이 소문이 되되(기획), 문구·선별은 GM이 통제.

1. 봇이 `행동로그`에서 눈에 띄는 항목을 **소문 후보**로 `소문` 시트에 자동 적재(`출처=자동`, `상태=후보`).
   | 컬럼 | 예 |
   |------|----|
   | `일차` | 4 |
   | `출처` | 자동(행동로그) / 수동(GM) |
   | `내용` | 누군가 의무실에서 오래 이야기하고 나왔다 |
   | `상태` | 후보 / 확정 / 발송 |
2. GM이 아침 루틴에서 후보를 골라 문구를 다듬고 `상태=확정`. 직접 새 소문을 `출처=수동`으로 추가해도 됨.
3. 소문일(주 1회)에 봇이 `확정` 행을 **무작위 수신자 3~5명**에게 DM, `상태=발송` + `행동로그.소문화=O` 표시. (수신자는 항상 무작위 — 대상 지정 없음)
- 이성 낮은 수신자에겐 왜곡 필터 적용.

## 7. 시트 한눈에 (GM이 만지는 곳)

| 시트 | GM 작업 | 빈도 |
|------|---------|------|
| `설정` | 오늘의 환경·현재 일차·단상 명단·소문 요일 | 매일/이벤트 |
| `진입`(조사 시트) | 장소명·진입 문구·오픈 일자. `현재 조사 가능`은 **봇이 자동 개방** | 사전/수시 |
| 장소 워크시트(조사 시트) | 조사 포인트·문구·**조사 가능 직군**·오픈 일자·획득물·재화 | 사전/수시 |
| `예외`(조사 시트) | 특정 캐릭터에게 포인트 접근 부여 + 특수 문구 | 수시 |
| `관리`.`출석` | **컬럼이 반드시 있어야 함**(없으면 전원 출석 불가). 값은 봇이 관리 | 사전 1회 |
| `소문` | 후보 선별·문구 확정 | 매일 |
| `고발` | 진위 판단·`처리` | 매일 |
| `부탁지령` | 내용·일정·경중·보상 | 사전/이벤트 |
| `추적` | 인물별 최대 5 단서(추적1~추적5) | 사전 |
| `이성` | 인물별 이성문구1(≤60)·이성문구2(≤30) | 사전 |
| `상점` | 아이템·회복 수치 | 사전 |
| `명단`/`관리` | 직군·목표, 건강/이성 점검 | 사전/매일 |
| `운세`/`커스텀` | 문구 풀 | 사전 |

> 봇 전용(GM 읽기만): `행동로그`(타임라인), `투표`(집계), `추적기록`(추적 수령 이력).
> `부탁지령`은 **GM·봇 공용** — GM이 지령을 적고 수동 전송 후 상태를 '전송됨'으로,
> 봇이 `[결과 보고/키워드]`를 받으면 상태='완료됨' + 완료 일차/시각/내용을 쓴다.
