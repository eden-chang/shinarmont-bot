> 8개 설계 문서 + 3건 감사(코드베이스 실현가능성 / 문서 정합성 / 구현 분해)를 코딩 관점으로 통합한 **코딩 에이전트 1차 참조**.

## 1. 착수 전 확정 아키텍처 결정 (감사 반영)

### 1.1 BOT_TYPE & 레지스트리 🔴 (필수 수정)
단일 `BOT_TYPE=shinarmont`를 쓰되, 기존 registry가 패키지명(stats/investigate)을 하드코딩 게이팅하므로 그대로 두면 상태확인·스탯변경·사용(stats)·진입·조사(investigate)가 **전부 차단**된다. → `commands/registry.py` **3곳 수정**:

1. `discover_commands()` 서브디렉토리 목록(`registry.py:327` `['default','store','stats','system','investigate']`)에 **`'shinarmont'` 추가** — 안 하면 신규 명령어 파일이 스캔조차 안 됨.
2. `_detect_package_from_path()`(`registry.py:657`)에 `shinarmont` 분기 추가.
3. `get_command_by_keyword()`·`get_enabled_commands()` 게이팅에 **`bot_type=='shinarmont'`면 패키지 필터 우회(allow-all)** 분기 추가 — `COMMAND_FILTER`·enabled·universal 검사는 그대로 유지하고, 그 뒤 패키지별 stats/investigate/store 차단만 건너뛴다.

- 그 결과: 모든 슬롯 `BOT_TYPE=shinarmont` + `INVESTIGATION_ENABLED=True`(전역). 슬롯 분리는 `BOTn_COMMAND_FILTER`로만. (검증: `COMMAND_FILTER`는 게이팅 2번째라 그대로 적용됨.)
- investigate 명령어(진입/조사)는 `investigation_sheets_manager` 필요 → `INVESTIGATION_SHEET_ID` 연결 유지.
- 신규 `commands/shinarmont/` 명령어는 `universal=False`로 두어도 shinarmont allow-all로 통과(명확성 위해 명시).

### 1.2 스프레드시트 3개 & 매니저 🔴
- `SHEET_ID`(기본), `SYSTEM_SHEET_ID`(시스템, **신규 매니저 필요**), `INVESTIGATION_SHEET_ID`(조사) — 각기 다른 ID.
- **세 번째 매니저 배선**(투자 매니저 패턴 복제): `config/settings.py`에 `SYSTEM_SHEET_ID` 속성 → `main.py`에 `_connect_system_sheet()`(=`_connect_investigation_sheet` 복제, `main.py:290`) → `_initialize_bot_systems`의 `router_kwargs`(`main.py:371`)에 `system_sheets_manager` 추가 → 명령어 `__init__`에서 `kwargs.get('system_sheets_manager')`.

### 1.3 `행동로그` 최종 스키마 & 기록 대상 🔴 (통일)
- **컬럼(9열, 순서 고정)**: `일시, 일차, 종류, 행위자, 대상, 요약, 상세, 능력치변동, 소문화`
  - `상세` = 교류 농도 / 고발 사유 요약 / 회복량 등 한 줄. `능력치변동` = "이성 -4" 등/'-'. `소문화` = 공란/O.
  - **행위자·대상 = 이름**(아이디 아님).
- **기록 대상(`종류` enum) = 추적 · 고발 · 결과보고 · 교류 · 의무실** (사용자 확정 목록). **조사·대화는 로그 안 함**(§5.5/5.7에서 append 제거). **투표는 `투표` 시트에만**, 과반 확정 시 `행동로그`에 집계 1줄(`종류=투표결과`).
- append는 위치 배열 → `action_log.append(...)` 헬퍼가 9열 순서를 단일 소스로 보장.

### 1.4 상태 저장 최종
| 상태 | 저장 |
|------|------|
| 소지금·소지품·건강·이성·직군 | `관리` 시트 |
| `오늘추적`(0/1)·`오늘조사`(0~2) | `관리` 시트 (GM 트래킹, 스케줄러 0시 리셋) |
| `오늘대화여부`·`오늘고발`·`오늘의무실`·`오늘대화상대` | 봇 JSON(`state/{슬롯}/game_state.json`, 날짜 스탬프로 자동 만료) |
| `어제대화상대` | 저장 안 함 — `오늘대화상대`의 날짜에서 파생 |
| `출석`(빈칸/O) | `관리` 시트 컬럼 — 출석 1일1회 **판정 기준** |
| 입원 | `건강 ≤ HEALTH_HOSPITALIZE_THRESHOLD` 파생(무저장) |
| 생존(유죄 처분) | 봇 미저장 → 결과만 로그, 반영은 GM |

> **출석 저장 위치 이력**: 관리시트 MM/DD 마커 → JSON `오늘출석` → **`관리` 시트 `출석` 컬럼**(현재, 2026-07-16).
> 빈칸=출석 안 함 / `O`=출석함, 스케줄러가 00:00에 빈칸으로 되돌린다. 컬럼이 없으면 출석을 거절한다(fail closed).

### 1.5 모델 ID (검증 완료)
`claude-opus-4-8` / `claude-sonnet-5` / `claude-haiku-4-5`는 **실존 현행 모델**(claude-api 레퍼런스 확인). 감사에서 "가짜 ID"로 본 것은 지식컷 아티팩트 → **수정 불필요**. 단 `anthropic` 패키지가 `.venv`에 **미설치 → `pip install anthropic` 선행**. AI 설계의 `output_config.format`(Structured Outputs)·`stop_reason=="refusal"`·`cache_control`은 현행 SDK와 일치(레퍼런스 확인).

### 1.6 게임플레이 세부 — 기본안 (조정 가능, 감사 B-항목 해소)
| 항목 | 기본안(확정) |
|------|------|
| 의무실 **세션 연결** | **답글 스레드**(`utils/reply_threads`)로 이어감(구현됨). 봇이 보낸 답글 `status_id`를 세션에 등록 → 사용자가 **대괄호 없이 답글만 달아도** 그 타래로 라우팅(핸들러 `_resolve_routing`). 세션은 `session_id`로 관리해 **사용자당 다중 타래 공존**. 비밀대화 세션 연결은 미구현(추후). |
| 의무실 **회복 타이밍** | 시작 시 회복 **없음**. 러셀 선생이 대화 흐름을 보며 **스스로 마무리(concluding)** 할 때 **1회** 처치 결과를 `관리`에 반영. 발화 최소 2·이상 3~6·최대 8(코드가 경계 강제). 처치 종류/수치는 AI(`doctor_treatment`)가 결정→코드가 `DOCTOR_TREAT_DELTA_MIN/MAX`로 클램프, AI 꺼지면 규칙 폴백. 일일 제한은 **시작한 날** 기준 소모(자정 넘겨 이어가도 시작일). `[대화 끝내기]`=처치 없이 종료. |
| 비밀대화 **릴레이** | 봇이 상대에게 대화 발생 사실만 알리는 연출(정보 릴레이 아님). 멘션 카운트=봇이 태그된 멘션 기준 캐릭터당 3·총 6. |
| **투표 형식** | `[투표/유죄/대상]`·`[투표/무죄/대상]` (1인1표 키 `(일차,대상,투표자)`에 대상 필요). 단상 1인이면 대상 생략 허용. |
| **결과보고 매칭** | `[결과 보고/키워드]` → `부탁지령`에서 (대상=보고자, 키워드 일치, 상태='전송됨') 1건 매칭 → 그 행에 상태='완료됨'·완료 일차·완료 시각·완료 내용을 쓰고 `보상` 지급. **상태 열이 곧 중복 방지 마커**(먼저 쓰고 나중에 지급). 전송은 GM 수동. |
| **도박 규칙** | 아래 §6-D 표준안(슬롯 3릴/배당표, 크랩스 pass line). 베팅 상한 `BET_MAX`, 일일 손실 한도 옵션. |
| **이성문구 발신** | 이성이 바뀌는 명령(교류/의무실/사용/조사) 직후 + 스케줄러 일일 스윕에서 검사. `이성` 시트 `발송여부` 락 check-and-set. DM 발신은 검사한 슬롯 계정(스윕은 @SYSTEM). |
| **소문 후보 적재 기준** | `행동로그`에서 `소문화` 미표시 + 최근 N일차 행 중 무작위 표본(종류 무관). GM이 확정. |
| **distortion 규칙 폴백** | AI 실패 시: 마스킹=어절 일부·숫자를 `▓`로 치환(정규식 기반), 오정보=명단/장소 목록에서 1~2개 무작위 치환. 한국어 형태소 분석 없이 단순 규칙. |
| 입원 sticky | 아니오(건강 회복 시 자동 해제). |
| 이성문구 재발송 | 아니오(1회 고정, `발송여부` sticky). |
| 소문 발송일 우선순위 | `설정.소문 요일` 우선, 없으면 `RUMOR_WEEKDAY`. |

공통 형태: `from utils.imports import *` + `@register_command(...)` + `BaseCommand` 상속 + `__init__(self, sheets_manager=None, api=None, **kwargs)`에서 보조 매니저 수령 + `@dm_only`(해당 시). 표준 흐름: **DM게이트 → 파싱 → 대상/조건 검증 → 일일제한 → 락 → 재조회 → batch_update → 캐시무효화 → 행동로그 → 응답/DM**.

> **Sheets API 캐시 규칙**: 가변 시트(관리·투표·행동로그·이성 플래그·추적기록·부탁지령)는 `get_worksheet_data(..., use_cache=False)`로 **항상 최신**을 읽는다. 정적 GM 콘텐츠(상점·운세·도움말·단상·추적 원본단서·장소)만 `use_cache=True`(TTL `SHEET_CACHE_TTL`=90초, 쓰기 시 자동 무효화). 이미 읽은 행에서 컬럼 인덱스를 구할 땐 `[k for k in row if k!='_row_number'].index(col)+1`로 헤더 재조회를 피한다. 자세한 근거 → `docs/구현_결과_보고.md §9`.

## 7. 멀티 에이전트 오케스트레이션 전략

- **인프라 담당 1인**이 공유 집합 S(registry/settings/main/router)와 스케줄러 잡 등록을 **직렬** 처리. 나머지 에이전트는 S를 읽기 전용.
- **시그니처 계약 우선**: §5 유틸 public 시그니처를 P1 시작에 확정 배포 → 그룹 B/C/D는 mock으로 즉시 병렬.
- **config 키 배치 병합**: §3 키를 S2에서 한 번에 추가(설정파일 충돌 방지). 명령어는 `getattr` 참조만.
- **파일 소유 경계**: 신규 명령어 = 새 파일 1개/에이전트(무충돌). EXT-진입/조사는 서로 다른 파일이라 2인 병렬 OK. 각 에이전트는 **자기 산출물의 단위 테스트 동봉**.
- 병렬 그룹: **A**(유틸 5인) → **B**(6인)·**C**(3인)·**D**(3인)는 상호 병렬. **크리티컬 패스** = S1→S2→(A의 stat_gate/scheduler)→S4.

## 9. 검증 / 테스트 전략

`tests/` `unittest` 패턴, 시트/API는 페이크 주입, 순수 로직은 실제값. **일차·시각은 주입 가능하게 설계**(스케줄러/일차 테스트), **AI는 폴백 경로로 결정적 테스트**.

| 대상 | 테스트 |
|------|--------|
| game_state | check_and_set 경계·이월·재로드 원자성 → `test_game_state.py` |
| dm_guard | direct 통과/그 외 차단 → `test_dm_guard.py` |
| daily_counter·action_log | 페이크 매니저 append/증가·9열 순서 → `test_action_log.py` |
| target_helpers | 이름/mentions 해석, 자기/미등록 에러 |
| distortion | AI None 폴백 결정성, 임계 분기 |
| stat_gate | 입원 파생, 이성문구 sticky, 감소 하한0 |
| 추적 | diff(받은 것 제외)·소진 안내 |
| 도박 | 시드 고정 배당 정산·상한 |
| 명령어 | 스텁 context로 execute 스모크(DM게이트·일일제한) |
| 스케줄러 | 잡 멱등·0시 스윕(수동 트리거 함수 노출) |

**수동 E2E**: 5슬롯 `.env` 기동 → DM 전용 차단, 출석(운세+3달러)1회, 조사2/추적1 시트반영, 교류 양쪽 이성+이성문구 DM, 0시 리셋·감소, 소문 주간.
